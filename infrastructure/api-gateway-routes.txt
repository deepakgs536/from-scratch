API Gateway Manual Route Configuration Guide
============================================

Since AWS Academy blocks Terraform from creating API Gateway routes programmatically, 
you must manually create these routes in the AWS Console for your API Gateway.

Below is the complete list of HTTP methods, routes, and the Lambda function they should point to.

Cart Service
------------
GET     /cart/{userId}                      -> lambda-dev-ecommerce-cart
PUT     /cart/{userId}/items/{itemId}       -> lambda-dev-ecommerce-cart
POST    /cart/{userId}/items                -> lambda-dev-ecommerce-cart
DELETE  /cart/{userId}                      -> lambda-dev-ecommerce-cart
OPTIONS /cart/{userId}/items/{itemId}       -> lambda-dev-ecommerce-cart
OPTIONS /cart/{userId}/checkout             -> lambda-dev-ecommerce-cart
POST    /cart/{userId}/checkout             -> lambda-dev-ecommerce-cart
OPTIONS /cart/{userId}                      -> lambda-dev-ecommerce-cart
OPTIONS /cart/{userId}/items                -> lambda-dev-ecommerce-cart
DELETE  /cart/{userId}/items/{itemId}       -> lambda-dev-ecommerce-cart

OPTIONS /payments/initiate                  -> lambda-dev-ecommerce-payment
OPTIONS /payments/webhook                   -> lambda-dev-ecommerce-payment
